# Privacy Disclosures

This static Vercel version of That’s My Lingo stores demo gameplay state in the browser and uses Vercel Analytics and Speed Insights. It does not include accounts, payments, uploads, chat, backend databases, or server-side wallet persistence.

## Current data surfaces

- **Browser storage:** local demo game state such as Demo Coins, XP, tokens, streaks, mission claims, and history.
- **Vercel Web Analytics:** pageviews and custom events for gameplay and monetization-link interactions.
- **Vercel Speed Insights:** performance and Core Web Vitals measurements.
- **Mail links:** user-initiated outbound email links for merch, sponsor, founder, and creator campaign interest.

## Current non-data surfaces

The static build does not collect payment cards, cash balances, legal names, government IDs, precise location, contacts, photos, uploads, chat messages, or real-money gambling data.

## Event privacy rules

Custom event payloads must not include names, emails, raw creator codes, payment data, secrets, passwords, account tokens, or persistent cross-site identifiers. Use coarse labels and numeric tiers instead.

## Future account release

Before Firebase Authentication, Firestore, Cloud Storage, Cloud Functions, push notifications, crash reporting, or Remote Config go live, publish a reviewed Privacy Policy and Terms of Service. Add account deletion, export, and support flows where platform policy requires them.
