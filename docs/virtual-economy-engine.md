# Virtual Economy Engine

The virtual economy supports retention, progression, personalization, and content unlocks without creating gambling, stored value, or cash redemption.

## Reward sources

- Spins
- Daily quests
- Weekly events
- Season milestones
- Collection completion
- Feedback submissions
- Accessibility onboarding completion
- Community-safe actions

## Reward sinks

- Cosmetic themes
- Avatar frames
- Badge shelves
- Map zone decorations
- Sound packs
- UI skins
- Profile titles

## Economy guardrails

- No paid spins.
- No cash-out.
- No redeemable prizes.
- No odds improvement purchases.
- No crypto or tokenized gambling value.
- No prize ledger in the virtual wallet.
- No purchase requirement for core progression.

## Server-authoritative future

If persistent accounts are added later, wallet mutations should be server-authoritative, audited, rate-limited, and separated from any sweepstakes entry ledger.
