# Lingo image assets

Export the images from chat/design tools into this folder using these names:

- `lingo-badge-trophies.png` — badge/trophy grid artwork
- `lingo-demo-features.png` — demo features and reward icons board
- `lingo-combo-streak.png` — vertical combo/streak meter

- `lingo-live-feed-leaderboard.png` — live feed leaderboard panel
- `lingo-roadmap.png` — Lingo world/level roadmap
- `lingo-iconic-burst.png` — ICONIC gold logo burst
- `lingo-multiplier-jackpot.png` — avatar multiplier jackpot board
- `lingo-button-kit.png` — purple/gold game button kit
- `lingo-wordmark-dark.png` — Lingo wordmark on dark background
- `lingo-wordmark-transparent.png` — Lingo wordmark cutout/transparent-style asset
- `lingo-referral-crew.png` — referral/share character crew art
- `lingo-neon-light-effects.png` — neon streak and light-effect sheet

The static page references them as `/public/images/<filename>`.
